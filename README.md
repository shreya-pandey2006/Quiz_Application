# Quiz Application

A simple and responsive Quiz Application built using HTML, CSS, and JavaScript.

## 📌 Task Objective

Build a single-page quiz application that fetches 10 multiple-choice questions from an API and displays all questions together on the page.

## 🚀 Features

- Fetches 10 quiz questions from an API
- Displays all questions on a single page
- Four options for each question
- Allows users to select answers
- Calculates the final score
- Shows correct and incorrect answers after submission
- Restart Quiz option
- Loading message while fetching questions
- Error handling for API/network failures
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Open Trivia Database API
